**voy a realizar un organizador y unificador de PDFs**

El Organizador de PDFs es un programa
desarrollado en Python que permite unir
varios archivos PDF en uno solo.

Busca los documentos, los ordena
alfabéticamente y genera un archivo final.

Lo que hay que hacer es dentro de la carpeta dist hay que crear una
carpeta que se llame pdfs y dentro descargar o copiar los archivos
que quiera unificar, tener en cuenta que el programa los unifica por
orden alfabetico asi que podes cambiar los nombres con A,B,C asi
quedan como vos queres.

Luego hay que tocar el OrganizadorPDF. exe y se crea un archivo
en la carpeta pdfs que se llama final y dentro estan todos unificados.
